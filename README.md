# eQuantum Equipo

Portal interno de eQuantum preparado para `equipo.equantum.com.py`.

## Stack
- Next.js 15
- TypeScript
- Tailwind CSS
- Supabase (preparado para integrar)
- Vercel (próximo paso)

## Rutas iniciales
- `/login`
- `/dashboard`
- `/admin`

## Próxima etapa
1. Crear proyecto Supabase.
2. Configurar autenticación.
3. Crear tablas para usuarios, clientes, proyectos, documentos e informes.
4. Proteger rutas privadas.
5. Desplegar en Vercel.
6. Conectar el subdominio `equipo.equantum.com.py`.

## Variables
Copiar `.env.example` a `.env.local` y completar:

```
NEXT_PUBLIC_SUPABASE_URL=
NEXT_PUBLIC_SUPABASE_ANON_KEY=
```

## Importante
El repositorio debe ser privado porque contendrá la base del portal interno de eQuantum.
